# beautybeboclone

A static homepage clone of Beauty Bebo. It has a pink category menu, product cards, and a footer. Hover a category to open its submenu.

## Files

| File | What it does |
| --- | --- |
| `index.html` | The store homepage |
| `CSS/style.css` | Layout, menu, product cards, and footer |
| `img/` | Facebook and Instagram icons used in the footer |
| `submenu.html` | An early draft of the category lists, not linked from the homepage |

## How to run

Open `index.html` in a browser, or from this folder:

```bash
npx serve
```

Product photos are local stand-in images in `img/products/`. Each one matches the product type on the card, such as a lehenga, shampoo, or lipstick. They are not photos from the Beauty Bebo site.
